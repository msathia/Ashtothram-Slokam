# Noto Sans Tamil

`NotoSansTamil-Regular.woff` is the unmodified Noto Sans Tamil v2.001 font used by the hymn source:
https://vignanam.org/fonts/NotoSans/NotoSansTamil-Regular.woff

Self-hosted for consistent Tamil, superscript, and Vedic-accent coverage without depending on installed system fonts. Only the Saraswati reading text uses this font.
